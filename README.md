## About the template

This repository was built from a revised version of Yaoyao Liu’s **minimal-light** Jekyll template through the Digital Health Humanities CV workshop materials.

The template uses YAML files under `_data/` to populate education, employment, publications, presentations, grants, awards, and related CV content.

### Main data files

- `_data/experience.yml` — education and work-history entries
- `_data/pubscombined.yml` — publications, conferences, grants, awards, and creative work

For the original template documentation, see the upstream / workshop materials included with this repository.
